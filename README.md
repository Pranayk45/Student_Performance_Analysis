# Student Performance Analysis

## Overview
Student Performance Analysis is a data analytics project built using Python, SQL, SQLite, Streamlit, and Power BI. The project analyzes student academic performance and identifies trends through statistical analysis, data visualization, and interactive dashboards.

## Features
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Statistical Analysis
- SQL-Based Reporting
- Interactive Streamlit Dashboard
- Power BI Integration

## Tech Stack
- Python
- Pandas
- NumPy
- SQL
- SQLite
- Streamlit
- Power BI
- Matplotlib
- Seaborn

## Key Insights
- Analyzed relationships between study hours, attendance, and student performance.
- Calculated statistical measures including mean, median, standard deviation, and correlation.
- Generated visual reports and dashboards for data-driven decision making.

## Visualizations
- Score Distribution Analysis
- Course Performance Comparison
- Study Hours vs Score Correlation
